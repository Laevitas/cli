Using agents and the installed CLI

Browser agents can call window.laevitasTerminal.run({args:["agent","catalog"]}) and read structured output. Wallet connection requires the owner's approval. Commands do not run from URL parameters.

This browser build supports REST market data, wallet sign-in, eligible starter claims, balance, usage, quotes and Enterprise key management. Streaming, TUI dashboards, stdio MCP, local files and payment signing use the installed CLI. Credits and subscription rules are the same.

Credentials and command history stay in tab memory. Refreshing, disconnecting or session expiry clears them. Never paste a private key or seed phrase into the terminal. Each published CLI release updates the web build; reload to load an available update.
